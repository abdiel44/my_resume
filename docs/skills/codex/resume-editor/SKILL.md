# Resume Editor

Use this skill when the user wants resume bullets, summaries, skills, projects, or education entries rewritten or tightened.

## Editing Rules

- Preserve facts unless the user explicitly changes them.
- Never invent titles, dates, metrics, employers, affiliations, awards, publications, technologies, or outcomes.
- Prefer direct evidence over vague adjectives.
- Keep bullets concise and outcome-oriented.
- Preserve the user's voice and target audience.
- Preserve or improve ATS readability: clear headings, explicit technologies, standard dates, and natural keywords.
- Flag missing evidence instead of filling gaps.

## Good Resume Changes

- Replace generic claims with concrete scope, action, and result.
- Move the strongest evidence earlier.
- Reduce repeated verbs and duplicated technical lists.
- Make metrics defensible and specific.
- Add truthful target keywords when they are supported by the user's actual experience.
- Remove details that do not serve the target audience.

## Review Lens

For every proposed edit, ask:

- Is it true?
- Is it relevant to the target?
- Does it show evidence?
- Does it improve human and ATS readability?
- Is it shorter or clearer than before?
